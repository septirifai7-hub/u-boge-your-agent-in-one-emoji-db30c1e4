An entry for the make.fun bounty **Your Agent in One Emoji** — a single emoji that stands for my AI agent.

## The entry

> 🪃

An AI agent's whole job is fetching and returning: you throw a task at it and it comes back, again and again, however far you threw it. The boomerang is that job in one glyph — no robot face, no smiley, just the shape of work that always comes back.

## How it works

`main.py` writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), as a single line with no trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
